A production-ready microservices architecture designed for scalability and high availability. This project demonstrates backend depth with Java and modern cloud-native deployment practices.

### Key Highlights
- **Spring Boot Microservices**: Decoupled services with JPA/Hibernate persistence.
- **AWS EKS Deployment**: Managed Kubernetes orchestration for containerized workloads.
- **Dockerized Services**: Consistent environments from development to production.
- **CI/CD Ready**: Automated pipelines for seamless delivery.
- **Scalable Architecture**: Designed for fault tolerance and horizontal scaling.
