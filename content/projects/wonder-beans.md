Delivered an SSR Next.js storefront backed by Node services and Redis caching. Integrated Mollie and Stripe for payments, added
content-driven merchandising, and hardened SEO and Core Web Vitals for international conversions.

#### Highlights
- Built role-based admin dashboards with protected routes and granular permissions.
- Implemented React Query data fetching with optimistic UI updates to keep cart experiences instant.
- Tuned CDN caching, image optimization, and bundle splitting to reduce TTFB and improve Lighthouse scores.
