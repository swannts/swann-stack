Implemented listing search, geolocation filters, and secure agent onboarding across Spring Boot microservices. Leveraged AWS EKS
with HPA for elastic scaling, AWS RDS for transactional data, and CloudFront for optimized asset delivery to React clients.

#### Highlights
- Introduced Spring Cloud Gateway with rate limiting and JWT security for partner APIs.
- Automated infrastructure with Terraform modules and GitHub Actions, including blue/green deployments.
- Instrumented services with Prometheus/Grafana dashboards and centralized logging via ELK.
